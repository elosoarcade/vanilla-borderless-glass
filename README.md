# Vanilla Borderless Glass
Vanilla Borderless Glass is a texture pack for Minecraft Bedrock that removes the border from glass blocks without altering the rest of the texture. This includes all colors of glass as well as tinted glass.

This addon is optimized to run effectively on Realms and dedicated servers with minimal hardware resource consumption. ⚡
